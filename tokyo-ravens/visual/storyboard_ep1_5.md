# Stage 11 — Storyboard Planning (All Episodes)

**Input:** `script/ep*_screenplay.md` (Stage 10). **Format (§5.7):** per scene — shot #, framing
(WS/MS/CU), camera move, duration, one-line visual description; then an image-gen prompt per
key shot referencing `characters_db.json` + `locations.json` for visual consistency.
**Rule:** shot variety; respect 180°-rule within scenes; durations sum to ~22 min/ep (finale 24).
Style baseline: **Eight Bit anime house style, cel-shaded, modern urban-fantasy, deep-indigo /
vermillion / gold palette (onmyoudou ritual aesthetic).**

Key-shot image prompts use this recipe:
`[subject from characters_db visual_anchors] + [location from locations.json tags] + [style] +
[lighting/mood] + [composition]`
