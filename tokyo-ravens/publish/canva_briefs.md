# Stage 15 — Canva Publishing Briefs

**Input:** `visual/char_prompts.md`, `visual/bg_prompts.md`, `story/vol2_ep_outline.md`.
**Format (§5.11):** per asset type — canvas size, brand colors, typography, image placement
zones, copy blocks. **Brand palette (per spec §7, distinct from personal teal/orange):** deep
indigo `#1a1a3a` background, vermillion `#c0392b` / gold `#d4af37` accents, white `#f5f5f5` type.
**Build-once, reuse per episode** (§7.2): templates below; only swap image assets + text.

---

## A. Character Sheet Template
- **Canvas:** 1080×1350 (portrait poster) or A4 print.
- **Layout zones:** top header band (character name + role); center-left turnaround (front/side/
  back from char_prompts); center-right stat block (age / affiliation / shikigami / key trait);
  bottom expression row (3 faces).
- **Typography:** Display = bold serif (onmyoudou feel); Body = clean sans.
- **Copy blocks:** NAME, ROLE, 3 behavioral-anchor bullets, "Vol.2 RAVEN'S NEST".
- **Brand:** indigo bg, gold rule lines, vermillion name plate.

## B. Episode Title Card Template
- **Canvas:** 1920×1080 (16:9).
- **Layout zones:** full-bleed BG art (bg_prompts), centered episode number + title, small
  "TOKYO RAVENS — Vol.2 RAVEN'S NEST" kicker top-left.
- **Typography:** Display serif, large; episode no. in gold.
- **Copy blocks:** "EPISODE N", "TITLE", kicker.
- **Reuse:** Ep1 "Young Ravens' Academy" … Ep5 "One-Armed Oni".

## C. Storyboard Panel Template
- **Canvas:** 2480×3508 (A3) grid, or 1920×1080 with 2×3 panel grid.
- **Layout zones:** per panel — image slot, shot # + framing label, one-line description,
  duration tag. QC gate symbol between rows.
- **Copy blocks:** scene/shot IDs (S1-01 etc.), framing (WS/MS/CU), dur.
- **Reuse:** from visual/storyboard_ep1_5.md.

## D. Scene / Location Reference Template
- **Canvas:** 1080×1350.
- **Layout zones:** hero BG image (bg_prompts), location name plate, 3 tag chips (era / mood /
  scale), short description.
- **Copy blocks:** LOCATION, tags, note.

## E. Poster / Key-Art Template (one-page system infographic — spec §CANVA POSTER)
- **Canvas:** 1080×1350 (or A3).
- **Layout:** vertical flow of the 17 stages (icons + 2-word labels) in 4 bands (Research →
  Story → Visual → Publish); sidebar = 16-role skill-map legend; footer QC-gate symbol + legend
  "canon-locked at every stage"; CTAs "Scalable to Vol.1–17" / "Modular · Canon-Safe · Reusable".
- **Header:** "TOKYO RAVENS — Vol.2 RAVEN'S NEST" + "AI-Assisted Production Pipeline".
- **Palette:** indigo bg, vermillion/gold accents, white type.

Once templates exist, each new episode = new image assets + text swaps. No redesign.
